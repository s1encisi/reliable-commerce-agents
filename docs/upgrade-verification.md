## 已修复并验证的失败案例

1. 合法 UUID 被银行卡／SSN 模式误脱敏：保留 UUID 区间，仍遮蔽真正的卡号，已补回归测试。
2. 非流式聊天缺少会话关联和步骤落库：与流式路径对齐，真实 HTTP 评测现在读取实际工具记录。
3. 断流后无条件重发 POST：仅明确安全的读请求允许重试，未知业务结果不重新执行。
4. 整块核验输出中的换行丢失：统一 SSE 多行编码与 A2A 解析。
5. 未知模型被当作 GPT-4.1 计价：现在返回未计价，新提供方使用独立本币账本。
6. 只读查询成功掩盖后续被拒绝写入：增加受控交接信号，任务不再被误标完成。
