## 结论与边界

- 分类、价格上下界、最低评分和下架过滤在三条路径中均未出现违规；嵌入不可用时显式标记词法降级。
- 未知品类 quantum teleportation device 没有相关商品，但混合检索仍返回三个近邻。当前路径是候选召回，尚无经过校准的无结果门槛；保留这一失败，不宣称全部案例通过。
- 精确型号查询的词法首位正确，但 OR 分词仍召回同前缀型号。报告同时保留返回列表与 Precision@3，不把额外候选隐藏。
- 离线嵌入采用词元特征哈希，没有真实的同义词理解能力；排序数值只说明本组工程路径行为，不能用作真实嵌入模型提升证据。
- 基线是**同一当前版本的纯词法功能消融**，不是改造前历史版本；没有构造或声称改造前后收益。
- 每个案例、每条路径热身 1 次、测量 3 次；共 108 次测量。重复不是独立样本，顺序本地耗时不代表容量、SLA 或统计显著收益。
- 空相关集的 Recall/nDCG 为 null，另算是否正确返回空结果。Precision@3 的分母是请求的 3 个位置；JSON 另提供实际返回集精度。
- 运行时工作区有改动。JSON 的 git.head 是当时 HEAD；实际评测内容由 implementation_sha256 绑定，运行前后哈希一致。

## 复现

在仓库根目录执行。评测入口禁用私人环境文件、录制和云凭据，不接受外部数据库连接字符串，只启动独立测试容器。
输出路径已经存在时会停止，保护旧报告；重跑请使用新文件名。

~~~bash
APP_ENV_FILE=/dev/null RECORD=false LLM_PROVIDER=replay \
  uv run --project agents/python --no-sync python -m evals.retrieval \
  --output docs/evaluation/retrieval-rerun.json --repetitions 3 --warmups 1
~~~

评测器的 6 项测试覆盖计分、重复结果、空结果、独立约束检查、三路径真实 PostgreSQL 执行以及已有数据保护；
正式报告是在测试通过后单独运行生成，不是用单元测试数量替代检索评测。
