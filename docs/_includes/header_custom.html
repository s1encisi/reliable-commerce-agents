{%- comment -%} 站点页头中的实时 star 数。 just-the-docs 会在 `#main-header` 内渲染该 include，位置在搜索框与 `aux_nav` 之间 —— 参见主题的 `_includes/components/header.html`。这是一个官方扩展点，因此无需把远端主题的 任何文件复制进来，主题升级也不会悄悄丢掉这段代码。 它为什么存在：just-the-docs 本身没有原生 star 数展示，因此本站此前什么都不显示 —— 项目自己的文档页上白白埋没了 star 数。这里只做社交证明：站内刻意不放任何 「请给本仓库点 star」之类的文案。 在 `md` 断点下 `.main-header` 是 `display: flex; justify-content: space-between`。 若有三个子元素，中间那个会孤零零地停在正中，因此用 `margin-left: auto` 把徽章贴到附加链接一侧。在 `md` 以下整个页头是 `display: none`， 所以按主题自身的设计，这仅用于桌面端。 图片只带 `height` 而**不带** `width`：shields.io 会按内容自适应徽章尺寸， 硬编码宽度会在 star 数多一位数字那天被压扁。改为在容器上用 `min-width` 预留水平空间，这才真正避免了布局抖动。使用 lazy + async， 因为装饰性徽章不应阻塞页头渲染。 {%- endcomment -%}
