面向 Agent 岗位（产品 / 应用开发）的学习笔记组，按「架构总览 → 智能体编排 → 工具与检索 → 记忆上下文 → 可靠执行 → 评测与成本 → 安全治理 → 问答手册」组织，每篇配图与常见追问清单。

| 文档 | 说明 |
